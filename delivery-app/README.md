# 출하·배차 확인 앱 (운송사 공유용)

창고(전기 없음)에서 휴대폰 하나로 쓰는 **출하 배차 확인 앱**입니다.
회사 ERP와는 **별도의 앱**이며, **비용이 들지 않습니다** (Google 시트 + Netlify 무료).

## 업무 흐름

```
① 회사(관리)        ② 운송사             ③ 회사(관리)      ④ 창고 상차 담당
출하 등록      →    기사·차량 입력   →   승인 / 반려   →   차량번호 확인
(거래처·품목)       (이름·전화·차번호)                      상차 완료 + 거래명세표 문자/카톡 발송
[배차대기]          [승인대기]            [승인완료]         [상차완료]
```

- **운송사**: 배차 입력할 건만 크게 보입니다. 단가·금액은 보이지 않습니다.
- **회사**: 승인대기 건을 `✔ 승인` 또는 `반려`(사유 입력)로 처리합니다. 반려하면 운송사 화면에 사유가 보이고 다시 입력합니다.
- **창고 상차 담당**: 승인된 차량의 **차량번호를 큰 글씨**로 보여 줍니다. `✔ 상차 완료`를 누르면 차량번호를 한 번 더 확인하고 기록합니다. 그다음 기사님께 거래명세표 문자를 바로 보낼 수 있습니다.
- **기사님**: 문자/카톡으로 받은 링크를 누르면 거래명세표가 열립니다 (인쇄·PDF 저장 가능, 로그인 필요 없음).

### 나이 드신 분도 쓰기 쉽게
- 큰 글씨, 큰 버튼, 역할별 화면 1개만 보입니다.
- 비밀번호는 숫자 패드로 누르고, 한 번 들어가면 휴대폰에 기억됩니다.
- 창고에서 신호가 약하면 **마지막으로 받은 목록**을 그대로 보여 줍니다.
- 화면을 켜 두면 1분마다 자동으로 새로고침됩니다.

### 비용
| 항목 | 사용 서비스 | 비용 |
|---|---|---|
| 데이터 저장 | Google 시트 | 무료 |
| 서버 | Google Apps Script | 무료 (하루 2만 회 요청 한도, 일반 사용에 충분) |
| 화면 주소 | Netlify | 무료 (지금 쓰시는 계정 그대로) |
| 문자/카톡 | 휴대폰 기본 문자앱·카카오톡 공유 | 무료 (문자는 상차 담당 휴대폰 요금제로 발송) |

## 설치 방법 (약 15분, 처음 한 번만)

### 1단계. Google 시트 만들기
1. 회사 Google 계정으로 <https://sheets.new> 를 열어 새 시트를 만듭니다. 이름은 예를 들어 `출하배차`로 합니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 누릅니다.
3. 열린 편집기의 `Code.gs` 내용을 모두 지우고, 이 폴더의 **`Code.gs` 내용을 통째로 붙여 넣은 뒤** 저장(💾)합니다.
4. 위쪽 함수 선택 칸에서 `setup`을 고르고 **▶ 실행**을 누릅니다.
   - 처음 실행하면 "권한 검토" 창이 뜹니다. 본인 계정 → **고급 → (안전하지 않음)으로 이동 → 허용**을 누릅니다. (본인이 만든 스크립트라 안전합니다.)
5. 시트로 돌아가면 `출하`, `설정` 탭이 생겨 있습니다.

### 2단계. 비밀번호·회사 정보 입력
`설정` 탭에서 **값** 칸을 고칩니다.

| 항목 | 설명 |
|---|---|
| 회사PIN | 회사(관리자) 비밀번호 — 기본값 1111, **꼭 바꾸세요** |
| 운송사PIN | 운송사에 알려 줄 비밀번호 — 기본값 2222 |
| 상차PIN | 창고 상차 담당 비밀번호 — 기본값 3333 |
| 상호·대표자·사업자번호·주소·전화 | 거래명세표의 "공급자" 칸에 인쇄됩니다 |
| 창고주소 | 승인되면 운송사 화면에 안내됩니다 |

> 비밀번호는 숫자로만 정해 주세요 (화면의 숫자 패드로 누릅니다). 세 비밀번호는 서로 달라야 합니다.

### 3단계. 서버 배포 (웹 앱으로 공개)
1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. 톱니바퀴 ⚙ → **웹 앱**을 고릅니다.
3. 설정:
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르면 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사합니다.
5. 이 폴더의 `index.html`을 메모장으로 열어, 아래 줄의 주소를 복사한 주소로 바꿉니다.
   ```js
   var API_URL = 'https://script.google.com/macros/s/여기에_웹앱_ID/exec';
   ```

### 4단계. Netlify에 올리기
1. <https://app.netlify.com/drop> 에 접속합니다 (기존 Netlify 계정으로 로그인).
2. `index.html` 파일이 들어 있는 **폴더**를 화면에 끌어다 놓습니다.
3. 나온 주소(예: `https://xxxx.netlify.app`)가 앱 주소입니다. **Site settings → Change site name**에서 기억하기 쉬운 이름으로 바꿀 수 있습니다.
   - 기존 주소(poetic-toffee-adb3e5)를 그대로 쓰려면, 해당 사이트의 **Deploys** 탭에 폴더를 끌어다 놓으면 됩니다.

### 5단계. 나눠 주기
- 운송사, 창고 상차 담당, 회사 담당자에게 **앱 주소 + 각자의 비밀번호**를 보냅니다.
- 휴대폰에서 주소를 연 뒤 **홈 화면에 추가**하면 앱처럼 아이콘으로 열 수 있습니다.
  - 안드로이드(크롬): 오른쪽 위 ⋮ → 홈 화면에 추가
  - 아이폰(사파리): 아래 공유 버튼 → 홈 화면에 추가

## 자주 묻는 질문

**Q. 서버 코드를 고친 뒤에는?**
Apps Script에서 **배포 → 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포**를 눌러야 반영됩니다. (주소는 그대로 유지됩니다.)

**Q. 비밀번호가 새어 나갔어요.**
`설정` 탭에서 값만 바꾸면 즉시 적용됩니다. 기존 사용자는 다음 새로고침 때 다시 비밀번호를 입력하게 됩니다.

**Q. 지난 기록은 어디서 보나요?**
Google 시트 `출하` 탭에 모든 기록(등록·배차·승인·상차 시각, 확인자, 명세표 발송 시각)이 쌓입니다. 엑셀로 내려받을 수도 있습니다.
앱 화면에는 회사는 최근 30일, 운송사는 최근 7일, 상차 담당은 승인 건만 보입니다.

**Q. 카카오톡 버튼을 누르면?**
휴대폰의 "공유하기" 창이 뜹니다. 여기서 **카카오톡 → 기사님**을 고르면 됩니다. 공유 기능이 없는 휴대폰에서는 내용이 복사되니 카톡 대화방에 붙여 넣으면 됩니다.

**Q. 시트의 열 순서를 바꿔도 되나요?**
`출하` 탭의 열 순서·제목은 바꾸지 말아 주세요. (보기 좋게 하려면 별도 탭에서 필터/피벗을 쓰시면 됩니다.)
